# Tên chương: một câu dễ nhớ

Một đoạn mở đầu 2–3 câu: chương này giải quyết vấn đề gì, vì sao người đọc nên quan tâm.

## Câu chuyện đời thường

Kể một tình huống quen thuộc (quán ăn, siêu thị, xếp hàng, thư viện, giao hàng...) để người đọc "cảm" được vấn đề trước khi học tên gọi.

::: {.box kind="kid" title="Hiểu nhanh qua ví dụ đời thường"}
Một phép so sánh ngắn (3–5 câu), không dùng thuật ngữ. Xưng "bạn".
:::

## Tên khái niệm — "biệt danh dễ nhớ"

**Vấn đề:** Nếu không có cách làm này thì chuyện gì xảy ra?

**Ví dụ đời thường:** ...

**Giải pháp:** Ý tưởng chính trong 1–2 câu.

![Chú thích hình: nói rõ hình đang thể hiện điều gì](img/ten_hinh.png){width=85%}

```java
// Code ngắn nhất có thể để minh hoạ ý tưởng (thường 10–30 dòng).
// Comment tiếng Việt giải thích từng dòng quan trọng.
// Nếu có kết quả in ra, ghi kết quả vào comment cuối dòng.
```

**Khi nào dùng:** ...  **Khi nào không nên:** ...

::: {.box kind="warn" title="Cẩn thận: Lỗi người mới hay mắc"}
Một lỗi cụ thể và cách tránh.
:::

## Bài tập chương N

::: {.box kind="ex" title="Bài tập"}
★ **N.1** Bài dễ: nhắc lại / tự cho ví dụ đời thường.

★★ **N.2** Bài vừa: viết code nhỏ hoặc phân tích tình huống cụ thể.

★★★ **N.3** Bài khó: thiết kế mở, có đánh đổi; có thể nhờ AI phản biện.
:::
