# Master SEO / GEO Checklist

## 1. Crawl & Index

- [ ] Page trả status đúng
- [ ] Không bị robots.txt block ngoài ý muốn
- [ ] Không có noindex ngoài ý muốn
- [ ] Canonical đúng
- [ ] Redirect không loop
- [ ] Sitemap chứa URL quan trọng
- [ ] Googlebot có thể tải resource quan trọng
- [ ] Page có internal link để discovery

## 2. Architecture

- [ ] URL mô tả
- [ ] Hierarchy rõ
- [ ] Navigation crawlable
- [ ] Breadcrumb hợp lý nếu cần
- [ ] Không orphan page quan trọng
- [ ] Duplicate URL được xử lý

## 3. On-page

- [ ] Search intent rõ
- [ ] Title unique
- [ ] Meta description phù hợp
- [ ] H1 rõ
- [ ] Heading structure dễ đọc
- [ ] Intro trả đúng nhu cầu
- [ ] Không keyword stuffing

## 4. Content

- [ ] Nội dung people-first
- [ ] Có giá trị riêng
- [ ] Không copy/rewrite đơn thuần
- [ ] Fact quan trọng có nguồn
- [ ] Có experience/data/example khi phù hợp
- [ ] Nội dung còn mới
- [ ] Claims marketing có bằng chứng

## 5. Links

- [ ] Internal link hợp ngữ cảnh
- [ ] Anchor text mô tả
- [ ] External source đáng tin
- [ ] UGC link có chống spam phù hợp

## 6. Images/Video

- [ ] Ảnh gần nội dung liên quan
- [ ] Alt đúng ngữ nghĩa
- [ ] Ảnh được resize/compress
- [ ] Width/height giúp tránh layout shift
- [ ] Video có title/description/context

## 7. Structured Data

- [ ] Schema đúng loại
- [ ] Schema khớp nội dung hiển thị
- [ ] Không fake rating/review/entity
- [ ] Validate syntax

## 8. Mobile & Performance

- [ ] Mobile có đủ content chính
- [ ] LCP được kiểm tra
- [ ] INP được kiểm tra
- [ ] CLS được kiểm tra
- [ ] JS không quá nặng
- [ ] Third-party scripts được kiểm soát
- [ ] Cache/CDN hợp lý

## 9. GEO / AEO

- [ ] Câu hỏi chính được trả lời trực tiếp
- [ ] Heading rõ
- [ ] Facts có citation
- [ ] Entity rõ ràng
- [ ] Có original evidence nếu có thể
- [ ] Table/list/steps chỉ dùng khi hữu ích
- [ ] Không artificial chunking
- [ ] Không llms.txt ranking myth
- [ ] Không AI schema myth
- [ ] Không scaled AI spam

## 10. International SEO

- [ ] Locale URL ổn định
- [ ] Metadata được localize
- [ ] Content được localize theo intent
- [ ] hreflang đúng
- [ ] reciprocal hreflang
- [ ] self canonical
- [ ] x-default nếu phù hợp
- [ ] locale sitemap đúng
- [ ] không redirect chặn crawler

## 11. Measurement

- [ ] Search Console
- [ ] Analytics
- [ ] Index monitoring
- [ ] CWV monitoring
- [ ] Search query monitoring
- [ ] Conversion monitoring
- [ ] Content refresh process
