# Workflow — Create / Optimize Page

## 1. Define

Điền `templates/page-brief.md`.

Cần biết:
- page type;
- audience;
- intent;
- topic;
- conversion goal;
- locale;
- proof/data available.

## 2. Outline

Mẫu:

```text
H1: [clear page promise]

Intro:
- answer/position ngay
- product/value context

H2: Problem
H2: How it works
H2: Key benefits/features
H2: Evidence / benchmark / case study
H2: Comparison / alternatives khi phù hợp
H2: How to start
H2: FAQ content nếu có câu hỏi thật
CTA
```

Không ép template nếu không hợp intent.

## 3. Metadata

Tạo:
- title;
- meta description;
- canonical;
- OG/Twitter metadata nếu cần;
- hreflang nếu locale.

## 4. Content checks

- direct answer rõ;
- không keyword stuffing;
- claims có proof;
- nguồn chính thức;
- internal links;
- entity rõ;
- content unique.

## 5. Technical implementation

Kiểm tra:
- server-rendered/prerendered public content khi framework yêu cầu;
- crawlable links;
- canonical;
- sitemap inclusion;
- robots/index;
- semantic structure;
- image dimensions/alt.

## 6. Schema

Chỉ thêm schema phù hợp loại page và nội dung thật.

## 7. Final review

Dùng `checklists/master-checklist.md`.
