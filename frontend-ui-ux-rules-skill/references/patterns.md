# Modern Frontend Patterns

## Navigation
- Collapsible sidebar
- Grouped sidebar sections
- Breadcrumbs for deep hierarchy
- Sibling tabs
- Command palette
- Keyboard shortcuts

## Data workflows
- Master-detail split view
- Right contextual panel
- Saved views
- Search + filter toolbar
- Sticky table header
- Column controls
- Bulk actions
- Row context menu

## Interaction
- Inline edit
- Optimistic feedback
- Undo for reversible actions
- Progressive disclosure
- Context-aware commands
- Hover-revealed secondary actions

## Onboarding
- Empty-state onboarding
- Inline setup guidance
- Example data where appropriate
- Avoid long forced tours

## Technical apps
- Use logs, traces, topology, metrics, terminal output, and real product data as visual identity.
- Prefer monospace selectively for technical values.
- Dense layouts are acceptable if hierarchy remains clear.
