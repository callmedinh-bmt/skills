# Frontend Anti-Patterns

## AI-slop indicators
- every surface is a rounded card
- excessive gradients
- blue/purple neon glow
- glassmorphism on operational screens
- excessive pill badges
- huge centered headings in application screens
- floating cards with no workflow purpose
- repeating 3-column layouts
- generic icon + title + paragraph blocks

## Structural problems
- cards inside cards
- using borders instead of spacing
- too many equal-priority actions
- using cards for tabular data
- overusing modals
- hiding key actions behind unclear icons
- mixing search and filtering semantics

## UX problems
- placeholder-only forms
- vague errors like "Invalid input"
- clearing form data after validation failure
- empty state shown on network failure
- no loading feedback
- color-only status
- no keyboard focus
- hover-only critical interaction

## Visual problems
- random spacing
- random radii
- excessive shadows
- excessive font weights
- tiny body text
- all-caps labels everywhere
- overly wide text blocks
- huge whitespace in data-heavy apps

## Motion problems
- animating every element
- large scale transforms on hover
- floating cards
- slow page transitions
- motion without semantic purpose
